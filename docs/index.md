## About the app

TLS Reader is a desktop ebook reader for macOS, Windows, and Linux. It connects to the configured TLS Library service for sign-in and catalog access. An internet connection is required to sign in and load publications.

The reader is open source. Visit the [project on GitHub](https://github.com/thorrsson/tls-reader) for source code, release notes, and project information.
